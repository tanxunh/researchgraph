# Safe evaluation definitions

Only human-curated questions, identifiers and evidence locators are distributed.
No paper text, PDFs, admitted evidence snippets, real model outputs or private
execution traces are included. Frozen results and limitations are in
[Evaluation](../docs/evaluation.md). Query JSON is unchanged from the accepted pilot.
Backend build-context copies are byte-identical and support offline Docker tests.
Corpus-dependent runners require user-supplied manifests, papers and local mappings.
Do not interpret these identifiers as a bundled or automatically reproducible corpus.
